I built Chess Clock Online because most web-based chess timers are either outdated, bloated with ads, or missing official time control presets.

Key features built into the app:

⚡ One-Click Presets: Instant access to FIDE Bullet (1+0, 2+1), Blitz (3+0, 3+2, 5+0, 5+3), and Rapid time controls.

📱 Mobile First & Fast: Zero installs or signups required.

🎯 Ad-Light Experience: Clean UI that doesn't distract from the game board.
